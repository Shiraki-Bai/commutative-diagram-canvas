# v1.8.1 · 修正草稿载入存档后的整体撤销

## 修复

- 原命名存档载入只记录模型快照，未把源码草稿、视图、字号偏好及修订关系纳入同一撤销边界。
- 载入改为独立的 diagram-load 撤销项。Ctrl+Z 恢复载入前模型、源码文本和是否未应用、视图、选择、字号偏好及名称字段；恢复后同步当前自动草稿。
- 不合并两份图，不修改已保存存档。载入后若有编辑，先撤销后续编辑，再整体撤销载入。
- JSON 工程载入也接入相同的整体撤销；导入时不再继承旧草稿的未应用源码。
- 保留保存记录删除的撤销分支及普通绘图撤销行为。

## 验证

覆盖有／无未应用源码的草稿载入、完整状态回退、节点数量不合并、修订关系恢复、存档内容不变、后续编辑撤销顺序、记录删除与载入混合撤销。真实浏览器 Ctrl+Z 及刷新后草稿一致性检查通过，原回归继续通过。
