# v1.8.0 · 已保存交换图的可撤销删除

## 新增功能

- 载入列表每条记录最右侧加入无可见文字的叉号删除按钮，独立于名称载入按钮。
- 删除操作接入原有 Ctrl+Z／撤销按钮顺序，恢复完整保存记录，不改变当前画布。
- 持久化删除和恢复都回读核验。失败明确提示，必要时保留内存撤销备份；遇到其他窗口写入不同记录或同名记录，不自动覆盖。

## 界面优化

- “刷新列表”移至载入面板右上角，改为图标按钮，悬停／无障碍名称仅为“刷新”。
- 保留搜索条件、保存格式、其他绘图与快捷操作。

## 验证与边界

18 项存储适配检查、16 项删除／撤销界面检查及完整旧回归通过；真实鼠标点击叉号后用 Ctrl+Z 恢复持久化记录，未触发载入或改变画布。

撤销历史仅存在于当前会话，沿用原100步限制，关闭后不保留。Hana 存储删除使用正式 storage.global.delete 接口；实际 Hana 窗口内删除／恢复尚未独立复测，不以浏览器及模拟接口测试冒充现场验证。
