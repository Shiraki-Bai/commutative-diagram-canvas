# 版本与发布规则

## 用户明确约定

当前完整功能（开发时曾标记为 1.8.1）统一重新标记为 **1.6.0**，不回退功能。

**默认更新只递增第二个小数点后的数字：**

```text
1.6.0 → 1.6.1 → 1.6.2 → 1.6.3
```

只有用户明确提出要求时，才改变第一个小数点后的数字（例如由 1.6.x 改为 1.7.0）。不因新增功能、重构或修复数量自动提高中间位；主版本也不擅自变更。

## 一致性

- Hana App 的 manifest.json、package.json、入口日志及当前说明必须同版本。
- 构建脚本读取 manifest 版本，产物与校验文件名随之生成。
- Git 标签为 vX.Y.Z，更新公告放在 releases/vX.Y.Z.md，并同步到同名 GitHub Release。
- 不覆盖或移动已发布标签，不强推远程历史。
- 标签或 Release 已存在但内容不同，先确认，不能为了统一编号擅自覆盖。
