# v1.6.0 · 交换图画布统一版本与累计更新

按用户要求，将开发阶段标记为 **1.8.1 的完整代码与功能统一标为 1.6.0**。这是编号整理，不是回退到早期功能。此前 GitHub 已发布的 v1.5.2 标签与历史保持不动。

以下汇总 v1.5.2 之后、当前代码中实际具备的累计更新。未正式发布的开发编号说明已归档，不将它们伪装成既有 GitHub Releases。

## 新增功能

- **命名交换图库**：保存节点、连线、标签、弯曲/自环、网格布局、字号、线宽、行列间距、视图位置及未应用源码。载入后继续编辑，而非静态图片。
- **适配持久化**：HTML 使用当前浏览器存储；HanaApp 使用正式应用存储，每幅图独立保存，并在写入后回读校验。
- **载入搜索**：按名称关键词筛选记录；空搜索展示全部，点击记录复用已有载入保护流程。
- **可撤销删除**：每条已保存记录最右侧为叉号删除按钮，无可见文字。删除不载入记录、不改变当前画布；Ctrl+Z 或撤销按钮按操作顺序恢复完整记录。

## 交互优化

- 创建或点击箭头后自动进入上侧标签框，光标在文本末尾；点击节点后也自动进入节点名称框。空文本时光标在开头，普通输入不反复抢焦点，不在拖动中途激活节点输入。
- 左下角按钮顺序为 **源码、参数、载入、保存**；载入面板与源码、参数面板左下角对齐。
- 保存使用画布中央的命名弹窗；载入列表保持搜索与错误反馈。
- 刷新入口位于载入面板右上角，使用图标按钮，提示文字为“刷新”。

## 问题修复

- **整体撤销载入**：Ctrl+Z 恢复载入前的模型、源码草稿、视图、选择及字号状态，不把草稿与已载入存档合并。载入后有编辑时，先撤销后续编辑，再撤销载入。
- JSON 工程载入接入同一撤销路径，不继承旧草稿的未应用源码。
- 删除或恢复存储失败时明确提示原因，保留必要的撤销备份；遇到其他窗口写入的不同记录，不静默覆盖。

## 验证

- 18 项交换图库存储/校验、14 项保存载入基础界面、13 项新入口和搜索布局、16 项删除撤销、15 项载入整体撤销检查通过。
- Edge 真实鼠标与快捷键测试覆盖节点/箭头聚焦、关闭标签重开载入、删除后 Ctrl+Z 恢复、载入后 Ctrl+Z 回到原草稿及刷新后内容一致性。
- 22 项源码解析、24 组几何、245 个箭头连接断言及135组非目标箭头对比通过。
- HanaApp 使用相同前端代码；本次未把浏览器或模拟存储测试宣称为 Hana 窗口内的逐项现场测试。

## 兼容性与限制

- 现有图形模型、命名记录格式和持久化键保持不变；应用 id 不变，不主动删除旧草稿或已保存记录。
- 已装开发编号 1.8.1 的用户可能看到版本降低提示，这是本次授权整理；通过 Hana 正式确认安装，不卸载数据来绕过。
- 撤销历史仍仅限当前会话、最多100步，关闭后不保留。重要图请保留备份。
- HTML 文件位置、浏览器或隐私模式变化可能影响本地记录；HTML 与 HanaApp 不自动同步。
- Snippets 函数、重复编号镜像和嵌套占位符等仍有明确限制；不支持任意 TikZ 源码。
