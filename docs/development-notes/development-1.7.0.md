# v1.7.0 · 箭头命名自动聚焦与保存／载入交互优化

本文件为开发交付公告，不代表 GitHub 标签或 Release 已创建。

## 交互优化

- 拖动创建新箭头、点击已有箭头，以及创建／选择自环时，自动聚焦上侧标签输入框，光标置于文本末尾；空文本时为起始位置。
- 焦点处理仅发生在这些触发点，不在普通刷新或输入时反复移动光标。
- 原“保存／加载”入口拆为“保存”“载入”。保存弹窗居于画布中央，自动聚焦名称；确认后复用既有持久化写入及回读校验。
- 载入列表位于按钮上方，每项显示图名；顶部名称关键词搜索不区分大小写，空查询展示全部记录，未匹配有明确反馈。
- 点击图名复用已有载入逻辑和当前内容替换保护；同名覆盖保护继续保留。

## 兼容与范围

没有改变 1.6.0 已保存图的数据结构、存储键或模型。旧记录可直接载入，无需迁移。存储适配器、图形几何、快捷键和其他绘图行为保留。

## 验证

- Edge 本地 HTML 的真实鼠标拖动创建箭头和点击已有箭头测试通过，焦点和光标位置符合要求；输入中途光标不被自动移到末尾。
- 12 项保存／载入新交互检查通过，包括弹窗居中、列表锚定、搜索／空搜索／无匹配、条目点击载入、同名保护。
- 12 项存储适配测试及完整旧回归通过，包含关闭原标签后重开同一 HTML、载入完整可编辑图。
- HanaApp 使用相同前端代码，安装后的实际焦点、存储重开行为仍需在授权运行环境中核实，未以浏览器测试冒充现场验证。
