# 版本与发布规则

沿用现有 `主版本.次版本.修订版本`（X.Y.Z）命名，当前为 1.5.2。本次获得授权将两套源码一起入库，并首次只发布 1.5.2。

- 主要版本：需要明确迁移的不兼容变更。
- 次要版本：向后兼容的功能新增。
- 修订版本：不改变预期用法的问题修复。
- manifest.json 与 package.json 必须同版本；构建脚本读取 manifest，不猜版本。
- Git 标签为 vX.Y.Z，每个待发布版本对应一份 releases/vX.Y.Z.md 中文公告。
- 公告只记录代码、测试与版本资料可核对的内容；新增、修复、优化、不兼容变更按实际有无列出。
- Release 应关联已推送标签，附 HTML、Hana App ZIP 和 SHA256SUMS.txt；不得强推或移动已发布标签。
- 历史版本资料不足时先确认，不从当前代码倒造以前的提交。

仓库首次提交是当前源码快照。v1.5.2 是第一次 GitHub Release，不代表此前版本已在 GitHub 发布。
