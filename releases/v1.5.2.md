# v1.5.2 · 双线／三线箭头连接修复

这是本私有仓库的首次 GitHub Release，发布当前可核对的 1.5.2 源码与构建产物。不补造以前的 Git 提交、标签或 Releases。

## 问题修复

- 修复双线、三线箭头主体在头部之前被统一截短的问题。
- 移除造成错位的内侧 V 形连接线，让各偏移线条直接接到原箭头头部斜边；三线中轴接到尖端。
- 同一连接算法覆盖直线、左／右弯和四方向自环；保留原箭头头部形状、线宽、节点及布局。
- 对比回归确认单箭头、单射尾钩、满射双头的绘制未因本次连接修复改变。

## 发布整理

- 将可编辑画布源码、Hana App 包源码、构建脚本和测试整合在一个仓库。
- 发布可直接打开的 HTML 与通过 Hana 扩展管理安装的 ZIP；附 SHA-256 校验清单。
- 排除浏览器测试配置、缓存、日志、本机环境与凭据文件；补充第三方许可证和可重建说明。

## 沿用能力（不是本版本新增）

可视化节点／箭头编辑、弯箭头与自环、受限 tikz-cd 源码双向编辑、数据型 snippets 适配，以及 Ctrl+Q 删除选中对象。HTML 与 Hana App 均可直接清空，不弹确认，并保留撤销。

## 验证

- 245 个多线主体／箭头头部连接断言通过。
- 135 组非目标箭头绘制与修复前版本对比保持一致。
- 24 组几何测试、22 组源码解析测试及 App 入口测试通过。
- Edge 本地 HTML 回归覆盖布局、源码往返、snippets、快捷键、真实鼠标连线／平移／自环，以及 13 项清空检查。

## 使用与边界

- Hana 用户下载 `commutative-diagram-canvas-HanaApp-1.5.2.zip`，在扩展管理器中安装。
- 无 Hana 时下载 `commutative-diagram-canvas-1.5.2.html`，用 Edge / Chrome 直接打开。
- 附件采用英文文件名以避免 GitHub 改写名称；`SHA256SUMS.txt` 对应下载后的实际名称。另保留初次构建的 `SHA256SUMS-local-filenames.txt`，它使用本地中文文件名，不用于直接校验英文名附件。
- 画布为结构预览，最终 TeX 排版可能存在字体和路径细节差异；源码解析不支持任意 TikZ。
- Snippets 默认内置 18 条起步规则。函数、重复编号镜像、嵌套占位符等尚未完整兼容，导入时会报告未启用条目。
- 此次不引入新的工程格式不兼容变更；旧的 double/triple 类型继续按已约定的共用头部语义显示。
