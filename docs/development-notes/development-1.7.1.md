# v1.7.1 · 节点命名自动聚焦

## 交互优化

- 点击节点后自动聚焦节点名称输入框，光标置于现有文本末尾，空文本时置于起始位置。
- 在 pointerup 确认未发生拖动后再处理焦点，不在 pointerdown 阶段打断连线和移动手势。
- 复用已有焦点票据机制，取消失效的延迟聚焦；普通刷新和输入不重新抢焦点。

修改仅涉及 app.js 的节点名称聚焦函数和指针释放分支；其他图形、保存载入和箭头命名行为保留。

## 验证

Edge 真实鼠标点击有名称／空名称节点，光标位置正确；名称输入中光标不被重置；从节点拖动连线期间焦点保留在画布，新箭头完成后仍自动聚焦箭头标签。原有回归继续通过。

HTML 与 HanaApp 同源构建。真实 Hana 窗口内焦点尚未独立复测；此公告不代表 GitHub Release 已发布。
