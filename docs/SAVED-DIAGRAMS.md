# 命名保存与载入交换图（统一版本 1.6.0）

## 使用

1. 点击画布左下角“保存”，中央弹出命名框并自动聚焦。
2. 输入名称，点击“确认保存”（或 Enter）。成功后弹窗关闭，状态栏显示“已保存”；只有写入并回读校验成功才给出此反馈。
3. 下次打开同一工具，点击“载入”，与源码、参数面板相同的画布左下角位置显示已保存交换图名称。顶部搜索栏可按名称关键词筛选，空搜索显示全部记录。
4. 点击某个名称后复用原载入逻辑。若当前画布或源码有内容，会明确要求“加载并替换”，可取消后先保存当前图。
5. 同名保存继续要求明确覆盖，不调用浏览器 confirm。未确认不会改动原保存记录。

当前统一版保持已有记录格式和持久化键；开发过程中已保存的命名记录无需重新保存。旧开发编号说明已归档。

## 删除与撤销

载入列表每项最右侧的叉号删除该保存记录，不会触发载入，也不清空当前画布。删除后可在当前会话按 Ctrl+Z（或点击原有撤销按钮）恢复完整记录。

删除与绘图操作共用撤销顺序：删除后又编辑画布时，先撤销最近的画布编辑，再撤销记录删除。撤销栈仍为原来的会话内最多100步，不在关闭／重启后保留；重要数据请备份。

删除和恢复都会核对持久化结果；无法确认删除时保留必要的内存备份，恢复失败也保留撤销项。若记录位置或名称被其他窗口占用，不会静默覆盖。原存储接口不提供跨窗口原子事务，仍建议避免并发覆盖。

右上角刷新图标提示为“刷新”，刷新不会清除搜索条件。

## 保存内容

节点名称及网格行列、全部现有连线类型和方向、上下侧标签、弯曲、自环方向、全局字号/线宽/行列间距、画布平移缩放位置，以及当前源码和其是否未应用。

未应用源码不会被强行解析或改变已保存画布；加载后作为未应用草稿恢复。节点和箭头仍可编辑，不是静态图片。恢复的是保存当时的快照，不是持续自动更新的命名版本；编辑后需要再次保存。

当前版将载入作为一个整体操作记录撤销。Ctrl+Z 恢复载入前的完整画布、未应用源码及其状态、视图位置、选中对象、字号偏好和名称字段，不把两份图合并。载入后若继续编辑，按顺序先撤销后续编辑，再撤销载入。保存的存档不因此改变。撤销历史仍仅在当前会话保留，重要内容请先保存。

## 持久化

- HTML：使用当前浏览器的 localStorage，每条记录独立键；关闭页面不会主动删除。清理浏览器数据、隐私模式结束、移动 HTML 文件或更换设备/浏览器可能无法访问旧记录。重要内容请另保留源码备份。
- Hana App：使用正式 storage.global，每条图独立键，与自动草稿分开；不随清空当前画布删除，不新增权限。
- 两端不会自动同步；没有引入云服务。
- 不支持多个窗口同时原子覆盖同名记录；写入前检查修改时间，写后回读，仍建议避免多窗口同时覆盖。不同记录使用不同键，不通过重写整个目录保存。

保存失败会显示具体错误（权限、配额或读回校验等）；若写入成功但列表刷新失败，会区分这两种结果。读取/校验失败不会替换当前画布。

## 源码

- diagram-library.js：独立记录格式、本地浏览器和 Hana SDK 存储适配器、记录校验及删除回读。
- diagram-library-ui.js：保存弹窗、名称搜索列表、内联确认、反馈与错误处理。
- index.html / style.css：左下角入口和面板。
- app.js：将新面板接入现有互斥展开逻辑，其余绘图动作保留。
- Hana App 的 ui/boot.js：绑定正式 SDK 适配器。

## 测试范围

18 项存储/校验测试，含新适配器重建后读取、写入拒绝、配额、回读失败；14 项浏览器界面检查；真实浏览器关闭原标签并新开同一 HTML 后读取并加载，可恢复节点、连线、标签、样式、布局和源码草稿。

Hana SDK 适配器做过模拟接口测试；实际安装后的端到端保存/重开需在 Hana 授权环境中核实，不将模拟测试写成现场验证。
