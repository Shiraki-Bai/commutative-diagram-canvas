# v1.6.0 · 命名保存与加载交换图

本文件是本次开发交付的中文更新公告，尚未代表已创建 GitHub 标签或正式 Release。

## 新增功能

- 画布左下角新增“保存／加载”入口，不改变原有四个工具按钮和绘图手势。
- 用户可命名保存完整可编辑交换图，包括节点、连线、标签、网格布局、字号/线宽/行列间距、弯曲/自环、视图位置和未应用源码。
- 已保存列表提供选择、刷新和加载；加载后仍可编辑。
- HTML 使用浏览器持久化，Hana App 使用正式应用存储，每幅图独立存储，不与临时自动草稿混为一谈。
- 同名覆盖和加载替换使用内联确认；保存写入后回读校验，失败明确提示原因，不误报成功。

## 验证

12 项存储/校验测试、14 项界面检查及关闭原浏览器标签后重新打开同一 HTML 加载测试通过；原有布局、箭头、源码、snippets、快捷键和清空回归继续通过。

Hana 存储适配器的错误和重建读取经过模拟接口测试，真实 HanaApp 安装后的端到端保存/重开未以模拟结果冒充。

## 注意事项

- 命名记录是保存当时的快照，修改后需再次保存。
- HTML 浏览器数据被清除、隐私模式结束、文件移动或更换设备后可能无法取回，重要图请备份源码。
- 不新增云服务或权限；HTML 与 Hana App 的记录不会自动同步。
- 加载可撤销图形替换，旧未应用源码不在撤销范围；覆盖前请先保存。
- 没有改变已有图形模型和旧草稿格式。旧版本不带交换图库入口，但新记录不会覆盖旧的自动草稿存储键。
